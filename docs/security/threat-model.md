# 安全威胁模型

## 系统边界与资产

信任边界包括：管理员浏览器、HTTPS 反向代理、FastAPI/WebUI、单实例采集 Worker、PostgreSQL、平台登录资料、云模型服务和备份存储。关键资产为管理员会话、平台 Cookie/浏览器资料、模型 API Key、评论与作者最小字段、任务/运行记录和数据库备份。

## 威胁与控制

| 威胁 | 可能影响 | 必须控制 |
|---|---|---|
| 暴力猜测/会话窃取 | 公网管理面被接管 | 单管理员、Argon2id、登录限速、TLS、安全 Cookie、会话轮换与注销撤销；不提供注册。 |
| CSRF/跨站请求 | 未经管理员确认修改任务或规则 | 所有状态变更校验 CSRF Token 和 Origin；生产同源部署并限制 CORS。 |
| XSS/恶意平台文本 | 管理员会话或操作被窃 | 评论、昵称、标题、链接按不可信文本处理；React 默认转义；禁止原始 HTML 注入。 |
| Cookie/Token/模型 Key 泄漏 | 平台账号或模型额度遭滥用 | 秘密只由服务端/Worker 持有；API write-only；日志、异常、截图、导出和 Git 扫描不得出现秘密。 |
| 模型 URL SSRF/重定向 | 访问内网、元数据服务或本机接口 | HTTPS only；解析 DNS 并校验 IP；拒绝 loopback、私网、link-local 和 metadata；禁用或逐跳校验重定向。 |
| 恶意模型输出 | 执行代码/SQL或意外联网 | 只接受受限 JSON DSL；结构、长度、操作符白名单校验；不执行表达式、不调用模型指示工具。 |
| CSV 公式注入 | 打开导出文件时执行表格公式 | 对以 `=`, `+`, `-`, `@` 等危险前缀开头的外部文本进行可靠转义；测试 CSV 与 XLSX。 |
| 数据库/备份泄露 | 评论、作者字段或凭据引用被暴露 | 最小网络访问、磁盘/备份加密、访问控制；浏览器资料单独加密备份；演练恢复。 |
| Worker 重复执行/状态错乱 | 重复采集或错误恢复 | PostgreSQL 持久任务状态、唯一键、单 Worker 串行队列、启动恢复检查；任务运行部分结果可恢复。 |
| 平台挑战或限流 | 账号受限或服务中断 | 识别后暂停并人工检查；不绕过验证，不自动换代理/账号，不做未批准重试。 |
| 采集范围膨胀 | 超出个人研究或平台访问边界 | 任务内容数/评论数上限、interval 不低于 60 分钟、默认一级评论、无自动联系和发布能力。 |

## 数据流边界

- 浏览器只访问同源 HTTPS Web/API，不直连 PostgreSQL、Worker、平台接口或浏览器调试端口。
- 只有 Worker/账号服务访问平台登录资料。API 不返回 Cookie、可复用会话令牌、本机资料路径或二维码；扫码登录在上游可见浏览器中完成，登录标记只记录最近一次校验时间。
- 评论文本只有在启用 AI 规则/语义判定时发送给管理员配置的模型服务。不得附带作者 ID、昵称、主页链接、Cookie 或账号信息。模型服务的具体保留策略由用户选择服务时确认。
- Web/API 与 Worker 到数据库走私有网络；公网仅暴露 HTTPS 管理入口。健康探针只回答存活/就绪状态。

## 验证要求

安全相关自动化测试仅使用合成数据、假的模型服务和隔离 PostgreSQL。发布前至少检查登录/CSRF、密钥不回显、SSRF 目标拒绝、平台文本转义、导出公式转义、容器端口暴露和备份权限。真实平台访问只由管理员手动发起小范围验收；出现限制立即停止。

首期为单管理员、单主机、单 Worker 架构，不声称具备多租户隔离、高可用或面对有针对性攻击的完整安全认证。公网部署前按实际反向代理、主机与秘密管理方式复核本模型。
