# 测试与验收计划

## 测试边界

自动化测试只使用固定 JSONL fixture、PostgreSQL 测试数据库和模拟模型 API。CI 不登录抖音/小红书，不使用真实 Cookie、账号或模型 Key。真实平台验收由用户在受控环境手动发起小范围任务。

## 测试层级

| 层级 | 目标 | 核心内容 |
|---|---|---|
| 单元 | 检查纯逻辑 | URL 规范化、关键词优先级、AI DSL 校验、状态机、字段白名单、Excel/CSV 序列化。 |
| 集成 | 检查模块边界 | PostgreSQL 唯一约束、事务、Alembic 升级、Worker 调用 MediaCrawler fixture、模型 API 超时/结构错误。 |
| API | 检查安全与契约 | 登录/CSRF、任务 CRUD、排队/取消、评论分页、快照、规则预览批准、导出响应。 |
| 前端 | 检查关键流程 | 登录、任务表单、调度配置、规则预览、搜索结果、历史快照和导出入口。 |
| 本地 E2E | 检查完整链路 | 关键词和链接任务各一条；interval/Cron 注册；评论去重和多次快照；批准规则；导出文件。 |
| 真实平台手动验收 | 检查账号与平台现况 | 每个平台一个有权使用账号，少量任务；发生验证/限流即停止。 |

## 数据固定样例

为 XHS 和 Douyin 分别维护去标识 JSONL fixtures，覆盖：

- 正常内容、一级评论、评论作者、点赞与回复计数。
- 缺失作者 ID、缺失昵称、无主页链接、缺评论 ID。
- 已匿名化上游字段；证明项目扩展只在受限白名单路径处理原始作者三字段。
- 同一评论多次运行、点赞/回复数变化、作者昵称或主页链接更新。
- 临时查询令牌从持久化 URL 中移除。

fixtures 不含真实账号信息、Cookie、私密消息或未经授权的个人数据。

## 关键验收用例

1. 未认证访问评论/任务接口返回 401；登录失败限速；注销后旧会话失效。
2. 任务一次只能选择一个平台和一种来源模式；字段不匹配返回 422。
3. 相同平台评论 ID 多次导入只保留一个主记录，每次运行各有一条快照。
4. exclude 关键词优先淘汰；include 任一命中后才进入 AI；关键词与语义规则同启用时按 AND 判定。
5. AI 规则草稿未批准时不得关联任务；批准后版本不可原位修改。
6. 模型 429、超时、无效 JSON 时保留评论，语义状态显示失败/待处理，作者字段不发送给模型。
7. 平台登录失效、挑战或限流不会自动重试或切换代理；任务状态和操作提示可读。
8. 同一 Worker 同时只执行一个采集 run；服务重启将活跃 run 标记 interrupted 并恢复启用计划。
9. CSV/Excel 导出字段与已批准记录匹配，不含 Cookie、临时签名查询参数或未批准作者字段。
10. PostgreSQL 备份可在隔离数据库恢复；恢复后任务、评论与快照关系完整。

## 本地命令基线

上游代码集成后，在项目根目录运行：

- uv run pytest -q：Python 单元/集成/API 测试。
- pre-commit run --all-files：文件头、YAML、空白和冲突检查。
- cd webui; npm run lint：前端静态检查。
- cd webui; npm run build：TypeScript 编译及生产构建。
- docker compose -f compose.dev.yml up -d postgres：启动本地 PostgreSQL。

当前仓库尚未导入上游源码；上述命令在上游集成前不作为当前项目可运行性承诺。

## 质量门禁

- 自定义 Python 代码的语句/分支覆盖目标分别为 80%/70%；上游源码不计入新增代码覆盖率分母。
- 任何失败不得通过跳过安全断言、降低限流测试或连接真实平台来掩盖。
- 发布候选必须完成自动验证、备份恢复演练和用户手动平台验收。
